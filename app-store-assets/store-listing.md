# Play Store Assets Requirements

## Required Graphics (Create these):

### 📱 Screenshots (REQUIRED)
- **Phone Screenshots**: 2-8 screenshots
  - Dimensions: 1080 x 1920px (16:9) or 1080 x 2340px (19.5:9)
  - Format: PNG or JPEG (no transparency)
  - Show key app features: task creation, calendar view, reminders

### 🖼️ Feature Graphic (REQUIRED)
- **Dimensions**: 1024 x 500px
- **Format**: PNG or JPEG
- **Content**: App logo + key features visual

### 🎭 App Icon (Already have, but verify)
- **High-res icon**: 512 x 512px
- **Format**: PNG (32-bit)
- **No transparency or rounded corners**

### 📱 Optional but Recommended
- **Tablet Screenshots**: If supporting tablets
- **TV Banner**: If supporting Android TV (1280 x 720px)
